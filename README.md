# Getting Started with the Project

## Clone Repo
```ZSH
git clone https://github.com/LifeAyush/seltzer.git
```

## Install Dependencies
```ZSH
npm install
```

## Run locally
```ZSH
npm start
```

## Opens at
```BROWSER
localhost:3000
```
